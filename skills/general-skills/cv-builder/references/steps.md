# The Seven Steps (verbatim prompt intent)

These are the user's own tested prompts. Follow their intent and structure closely — don't paraphrase away specifics like "action + task + result" or the exact column lists. Each step is usable standalone or as part of a chain.

## Step 1 — JD Extraction (recruiter lens)

Act as a recruiter analyzing the JD. Extract, in a clean structured table:
- Key skills required (technical + soft skills)
- Core responsibilities (day-to-day expectations)
- Hiring intent (what problem they're solving)
- Must-use keywords for ATS optimization
- Traits of a standout candidate

Input needed: JD.

## Step 2 — Full CV Rewrite

Rewrite the CV for this job without adding or inventing any information.
- Improve the professional summary
- Refine experience bullet points
- Optimize the skills section
- Use ATS-friendly keywords from the JD
- Make each bullet role-specific
- Focus on measurable impact and outcomes wherever possible
- Ensure clarity, strong action verbs, clean modern structure

Input needed: CV, JD.

## Step 3 — Bullet-Level Rewrite

Rewrite specific CV bullets for a role using: **action + task + result**.
- Concise, specific, directly aligned with the JD
- Strong action verbs, no fluff
- Each bullet reflects value, not just responsibility

Input needed: role title, JD, the specific bullets to rewrite.

## Step 4 — Role-Fit Matrix

Detailed table comparing the profile to the JD. Columns, in this order:
- Requirement from the JD
- My evidence (relevant experience/skills)
- Strength level (strong / medium / weak)
- What to emphasize in the CV
- What to address or explain in the cover letter
- Interview story to prepare

Be honest, specific, actionable — this is a self-assessment tool, not a pitch.

Input needed: background/CV, JD.

## Step 5 — Gap Analysis + Summary Realignment

Compare CV to JD and identify:
- Missing or underused keywords
- Weak or irrelevant sections
- Bullet points that need improvement
- Skills that should be prioritized or moved higher
- Any ATS-related issues affecting match score

Then rewrite the professional summary to improve alignment, without keyword stuffing or losing clarity. Natural, role-specific, easy to read.

Input needed: CV, JD.

## Step 6 — Hiring Manager Verdict

Evaluate the CV as if a hiring manager. Give a clear verdict: **shortlist / maybe / reject**.
Then:
- Key strengths in the application
- Weaknesses or gaps holding it back
- Specific edits that would quickly improve chances

Direct, honest, actionable. No generic feedback — if something is weak, say so plainly rather than softening it into vague encouragement.

Input needed: CV, cover letter (if available), JD.

## Step 7 — Full Application Pack

Using only real experience (no invention), produce:
- Optimised CV summary
- Top skills aligned to the role
- Tailored cover letter
- Concise recruiter DM
- Professional follow-up email

Consistent, role-specific, easy to use.

Input needed: background/CV, JD.
